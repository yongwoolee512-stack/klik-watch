# 영상 읽기 (watch-video)

영상 주소를 받아 (1) yt-dlp로 음성만 내려받고 (2) faster-whisper로 글로 바꾼 뒤 (3) 그 글을 읽고 사용자의 질문에 답한다.
영상 파일은 임시 폴더에만 두고, 글로 바꾼 결과는 `~/.klik/watch/<영상id>.json`에 저장해 같은 영상을 다시 묻으면 재사용한다.

## 실행

```bash
python "{baseDir}/scripts/watch.py" "<영상 주소>" --lang ko
```

- `{baseDir}`는 이 SKILL.md가 있는 폴더.
- 영어 영상이면 `--lang en`. 모델은 기본 `small`(빠름). 긴 영상이나 정확도가 필요하면 `--model medium`.
- 처음 실행하면 모델 파일(약 460MB)을 한 번 내려받는다. 1~2분 걸릴 수 있다고 사용자에게 미리 말한다.

## 준비물이 없을 때

스크립트가 `ModuleNotFoundError`로 멈추면 아래를 실행한 뒤 다시 돌린다 (Python 3.10 이상 필요):

```bash
python -m pip install --user --upgrade yt-dlp faster-whisper av numpy
```

Python 자체가 없으면 사용자에게 "파이썬(무료) 설치가 필요해요. 윈도우 터미널에 `winget install Python.Python.3.12` 를 치면 됩니다"라고 안내한다.

## 결과 다루기

- 스크립트는 마지막에 전체 자막을 인쇄한다. 그 글을 근거로 답하고, 영상이 말한 내용과 내 추측을 구분해서 말한다.
- 자막에 도구·제품 이름이 나오면 음성 인식이 틀릴 수 있다(예: "그래픽 파이" → Graphify). 캡션·화면 글자와 맞춰 보정한다.
- 인스타·틱톡은 공개 게시물만 된다. 비공개·로그인 필요 영상은 "받을 수 없음"이라고 말한다.
- 음악만 있고 말이 없는 영상은 자막이 비어 있다. 그때는 캡션(스크립트가 함께 인쇄)만으로 답한다.
